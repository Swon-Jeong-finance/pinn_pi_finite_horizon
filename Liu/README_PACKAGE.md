# Liu code package

This package is arranged for direct use from one working directory.

- Training, launch, evaluation, aggregation, and plotting scripts are in this
  directory.
- `auxiliary_tests/` contains regression tests and their test runner.
- Generated outputs, checkpoints, caches, notebooks, and prior ZIP archives
  are intentionally excluded.

Run all auxiliary tests with:

```bash
bash auxiliary_tests/run_tests.sh
```
